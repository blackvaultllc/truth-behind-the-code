# Sophia Stewart Book Collection Promotional Page

## Build
- Replace the blank home screen with one polished, single-page promotional experience.
- Use a black cinematic canvas, restrained Matrix-green accents, digital display typography, and readable body text.
- Add a lightweight, low-opacity canvas code-rain layer that pauses for reduced-motion users and never blocks interaction or readability.

## Sections
- Hero with the supplied headline, subhead, and smooth-scroll “Explore the Books” action.
- Short sourced biography and official About link.
- Conversion-focused three-book grid with distinct cover art, concise hooks, and clearly marked placeholder Amazon affiliate destinations.
- Four-stat impact band preserving the supplied numbers exactly.
- Front-end email signup confirmation, official contact link, disclosure, and official-site link.

## Visual assets
- Use official cover images when suitable source files can be verified; otherwise create professional cover treatments that clearly present each real title without posing as official cover reproductions.
- Keep the first screen cinematic and branded, with the books visible immediately below it.

## Quality and accessibility
- Mobile-first layout with a three-column desktop book grid and single-column mobile grid.
- Semantic landmarks, keyboard focus states, accessible labels, sufficient contrast, and reduced-motion support.
- Add page-specific title, description, social metadata, and canonical URL.
- Verify desktop and mobile rendering, smooth-scroll behavior, external links, and the signup confirmation in the live preview.

## Technical note
- The project uses its built-in React page structure, so the implementation will be one self-contained page at `/` rather than a separate static HTML file. No backend or third-party animation library will be added.
